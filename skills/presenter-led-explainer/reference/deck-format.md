# Deck format

A video folder:
```
videos/001-slug/
  script.md      the listening script
  deck.json      { "title", "lang", "slides": [ { "id": "s01", "title": "...", "notes": ["speaker note", "..."] } ] }
  scenes/s01.html, s01.js ...   one page per slide (the .js is optional)
  runtime/       copied from the skill: Reveal.js, scene.css, motion.js, belt.js, office.js
  index.html     generated by build.mjs, do not edit
  takes/         browser recordings (gitignored)
```
Ids run `s01`, `s02`, ... in slide order. `notes` are speaker notes only: shown in the N window (and with T), never part of the slide.

## A scene page
Copy `templates/scene.html`. The contract:
- `<body data-cues='[0.3, 4, 8]' data-loop="20">`: **cues** are the seconds (from when the slide appears) at which step 1, 2, 3
  start; **loop** restarts the slide after that many seconds with a quick fade. Leave `data-loop` out to play once and then rest.
  The slide is one click: the deck starts it on entering and pauses it on leaving. Opened alone, a scene plays by itself
  (Enter = replay, `?at=8` = start 8 seconds in, handy for checking the end state).
- `<div id="frame">` holds one or more `<div class="layer">` (an inline `<svg viewBox="0 0 1920 1080">` each) and `<div id="cap"></div>`.
  Several layers cross-fade; `data-switch='[0,2]'` on `<body>` shows layer 1 from step 2 (i.e. when cue 2 fires).
- `M.captions('...')`: the one caption line. Wrap the key word in `<em>` for orange. Keep it under about 60 characters.
- `M.start()` last.

## Animation (`M`, from runtime/motion.js)
`const A = M.layer('id')` returns a layer helper. Everything is a function of time, so stepping back and forth works:
- `A.track(elementId, t => ({x, y, s, r, o}))` move/scale/rotate/opacity an SVG element (`t` = seconds).
- `M.since(n)` = seconds since step n started (-1 if not yet). Use it to start motion at a cue.
- `A.spin`, `A.swing`, `A.bob`, `A.belt`, `A.smoke`, `A.camera`, `M.sprites`, `M.journey` cover rotation, loops, conveyors, a
  moving viewBox camera and parcels that drop, hop and ride. `belt.js` (conveyor queues, piles) and `office.js` are optional kits.
- Everything is a function of time, so a loop restart or a replay is always clean. Keep ambient motion running after the build.
- Add motion only where it explains something. A still drawing with a caption is a fine slide.

`examples/001-produktivitet/` is a finished 13-slide deck (Swedish) using all of this; read its `scenes/s03.js` and `s05.js`.
